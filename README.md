# Paint Essential (페인트 에센셜) v1.3.0 🎨

> **빠르고 가벼운 고성능 스마트 데스크톱 그래픽 에디터**

### 📌 v1.3.0 정식 릴리즈 내역
* **3대 핵심 마이크로 인터랙션(Micro-interactions) UX 도입**:
  - **커서 동적 인터랙션 가이드**: 도형 본체 호버 시 이동(`SizeAllCursor`), 조절 핸들 호버 시 리사이즈/회전 커서, 스페이스바 팬 조작 시 손 커서로 전환되어 직관적인 피드백 제공.
  - **도형 확정 예고 (고스트 인디케이터)**: 도형 선택 후 빈 캔버스에 마우스를 올리면 감쇠(30% Dimming) 및 `"✓ 클릭 시 픽셀 고정"` 캡슐 뱃지를 노출하여 확정 타이밍 직관적 예고.
  - **고스트 인디케이터 On/Off 토글 지원**: 도구 속성 사이드바 및 설정 다이얼로그(`F1`) 내 체크박스를 통해 사용 여부를 자유롭게 설정 (미사용 시 빈 공간 클릭으로 안전하게 선택 해제).
  - **스마트 포커스 하이라이트**: 모자이크, 순서 배지, 둥근 모서리 등 도구 전환 시 관련 사이드바 속성 컨트롤 그룹이 펄스 점멸하여 시선 자연스럽게 유도.
* **도형 선택 및 연속 그리기 사용성 완벽 정립**:
  - 도형 그리기 모드에서도 이미 선택된 도형의 핸들(크기/회전) 및 몸체(위치 이동)를 마우스로 자유롭게 수정 가능.
  - 신규 도형을 연속해서 삽입하고 싶을 때는 `Esc` 키 또는 빈 공간 클릭으로 선택을 해제한 뒤 자유롭게 그리기 가능.
* **전체적인 렌더링 파이프라인 및 성능 최적화**:
  - 스마트 뷰포트 갱신(`SmartViewportUpdate`)을 적용하여 4K 및 고주사율 디스플레이 환경에서 드로잉 렌더링 부하 최소화.
  - 마우스 드래그 스트로크 이벤트 쓰로틀링을 적용하여 브러시/연필/지우개 연속 드로잉 시 래그를 완전히 제거하고 60+ FPS의 매끄러운 조작감 제공.
  - 스포이드 픽셀 돋보기의 실시간 합성 레이어 캐싱을 구현하여 마우스 호버 시의 CPU 점유율 대폭 경감.
* **텍스트 입력(T) 도구 완성 및 클립보드 붙여넣기 강화**:
  - 텍스트 도구를 통해 글꼴, 폰트 크기, 스타일(굵게/기울임꼴/색상)을 자유롭게 편집.
  - 장문의 멀티라인 텍스트 붙여넣기 시 크래시 없이 텍스트 크기에 맞춰 바운딩 박스 자동 조절.
* **선택 영역 삭제(Delete 키) 개편 및 투명 선택 연동**:
  - `Delete` 키 입력 시 점선 선택 영역(Marquee)은 유지되면서 내부 이미지 및 도형만 스마트하게 삭제.
  - 투명 선택 토글 OFF 상태에서는 서브 컬러(색 2 / 배경색) 유지, 토글 ON 상태에서는 완전 투명으로 삭제.
  - 도형 레이어가 활성화된 상태에서도 선택 영역 내부의 이미지와 도형을 정확히 감지하여 삭제.
* **QA 종합 결함 8종 전수 수정 완료**:
  - 부모 레이어 삭제 시 자식 레이어 고아화(Orphan) 및 영구 실종 방지 (루트 레벨 자동 승격).
  - 레이어 구조 조작(추가/삭제/순서/인덴트) 시 HistoryManager 연동으로 드로잉 소실 방지.
  - 선택 영역 잘라내기(`Ctrl+X`) 및 플로팅 이동 커밋의 Undo 완전 지원.
  - 캔버스 90° 회전 및 좌우 반전 시 벡터 화살표 각도 수학적 보정.
  - 스텝 배지 도구(`K`) Undo 시 번호 카운터 롤백 복원.
  - 4K 대용량 이미지 톤 보정 시 렌더링 프리징 방지.
  - 상태 표시줄 캔버스 안내 툴팁 및 `F1` 환경설정 표준 단축키 바인딩.

## 🌟 주요 기능

### 1. 🎛️ 스마트 도구 모음 및 하위 모드 지원
* **도구 통합 버튼:** 사각형 도구(`U`)와 화살표 도구(`A`) 버튼 우측 하단에 서브 도구 표시가 제공됩니다.
* **우클릭 / 길게 누름:** 버튼을 우클릭하거나 길게 누르면 원하는 하위 도구를 선택할 수 있습니다.
  - **직사각형 (`U`):** 일반 직사각형, 둥근 모서리 사각형 (모서리 곡률 조절)
  - **화살표 (`A`):** 단방향 직선 (➡️), 양방향 직선 (↔️), 단방향 곡선 (↪️), 양방향 곡선 (🔄)
* **마지막 선택 도구 기억:** 자주 사용하는 하위 도구가 기본값으로 유지되어 빠르게 작업할 수 있습니다.
* **곡선 화살표 조절:** 곡선 화살표 선택 시 중앙 조절 핸들을 마우스로 드래그하여 곡률을 자유롭게 변경할 수 있습니다.

### 2. 🎚️ 스마트 도구 옵션 바
선택한 도구에 맞춰 옵션 입력창이 지능적으로 전환되어 세부 수치를 손쉽게 조절할 수 있습니다:
* **순서 배지 (`K`):** `" 시작 번호: "` (1 ~ 99 번 조절, 우클릭 시 숫자/영문 대소문자 스타일 선택 지원)
* **모자이크 / 블러 (`J`):** `" 블록 크기: "` (4 ~ 64 px) 드래그 즉시 실시간 픽셀화 반영
* **둥근 모서리 사각형 (`U`):** `" 모서리 곡률: "` (2 ~ 64 px) 실시간 라운딩 반영
* **페인트통 채우기 (`G`):** 투명 영역 채우기 허용 범위 (0 ~ 100 %)
* **마술봉 자동 선택 (`W`):** 유사 색상 선택 허용 범위 (0 ~ 255)

### 3. 🍞 깔끔한 복사 안내 알림
* `Ctrl+C` (선택 영역 복사), `Ctrl+Shift+C` (투명 배경 포함 복사), `Ctrl+X` (잘라내기) 시 화면 상단 중앙에 깔끔한 알림 배너가 부드럽게 나타납니다.
* 마우스 클릭을 가로막지 않아 연속적인 편집 작업을 방해하지 않습니다.

### 4. 🔲 사각 및 자유 영역 선택
* 사각형 선택(`M`) 및 자유 올가미 선택(`L`)을 지원하며, 선택 영역을 마우스로 자유롭게 이동할 수 있습니다.
* **투명한 선택:** '투명 선택' 활성화 시, 이동 및 붙여넣기할 때 배경 색상을 투명하게 처리하여 자연스럽게 합성합니다.

### 5. 🗂️ 독립 레이어 관리 & 필터 탭 (ALL / 레이어 / 도형)
* 이미지 레이어와 도형 레이어를 유연하게 관리할 수 있으며, 가시성 토글, 순서 변경, 하위 레이어 그룹화 등을 지원합니다.
* 레이어 패널 상단 `[ALL]`, `[레이어]`, `[도형]` 탭으로 원하는 유형만 모아서 조회할 수 있습니다.

## ⌨️ 단축키 안내

| 단축키 | 기능 | 설명 |
| :---: | :--- | :--- |
| `V` | 도형 선택 및 조절 | 8방향 크기 조절 핸들 및 회전 손잡이 제공 |
| `M` | 사각 영역 선택 | 원하는 사각 영역을 선택하고 이동 |
| `L` | 자유 올가미 선택 | 마우스 드래그로 자유로운 모양의 영역 선택 |
| `W` | 자동 선택 (마술봉) | 유사한 색상의 영역을 한 번에 자동 선택 |
| `B` | 브러시 | 부드러운 브러시 드로잉 [우클릭: 지우개] |
| `N` | 연필 | 정밀한 1픽셀 드로잉 [우클릭: 픽셀 지우개] |
| `E` | 지우개 | 불필요한 부분을 지우는 지우개 도구 |
| `G` | 페인트통 | 닫힌 영역을 선택 색상으로 채우기 |
| `I` | 스포이드 | 화면에서 색상 추출 (정밀 픽셀 돋보기 오버레이 지원) |
| `U` | 직사각형 / 둥근 사각형 | 사각형 도구 (우클릭/길게 누르기로 둥근 사각형 전환) |
| `A` | 화살표 도구 | 화살표 도구 (우클릭/길게 누르기로 직선/곡선 화살표 선택) |
| `J` | 모자이크 도구 | 드래그한 영역을 즉시 모자이크 처리 |
| `K` | 순서 배지 도구 | 클릭할 때마다 순서대로 번호 배지 삽입 |
| `[` / `]` | 선/브러시 굵기 조절 | 굵기 감소 / 증가 |
| `Ctrl + X` | 잘라내기 | 선택 영역을 클립보드로 잘라내기 |
| `Ctrl + C` | 복사 | 선택 영역을 클립보드로 복사 |
| `Ctrl + Shift + C` | 투명 배경 포함 복사 | 투명 배경이 유지된 고화질 이미지 복사 |
| `Ctrl + V` | 붙여넣기 | 클립보드 이미지를 캔버스에 붙여넣기 |
| `Ctrl + A` | 전체 선택 | 캔버스 전체 영역 선택 |
| `Ctrl + N` | 새 캔버스 만들기 | 프리셋 규격 또는 사용자 지정 크기로 새 캔버스 생성 |
| `Ctrl + S` | 저장 | 작업 중인 이미지를 파일로 저장 |
| `Enter` / 더블클릭 | 도형 고정 | 선택된 도형을 바로 아래 래스터 레이어에 영구 병합 |
| `Ctrl + E` | 아래 레이어로 병합 | 선택된 도형 또는 레이어를 바로 아래 래스터 레이어와 병합 |
| `Esc` | 선택 해제 | 선택된 도형 또는 선택 영역 해제 |
| `Delete` | 삭제 | 선택된 영역 또는 선택된 도형 삭제 |
| `Ctrl + Z` | 실행 취소 (Undo) | 이전 작업 단계로 되돌리기 |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 다시 실행 (Redo) | 취소했던 작업 다시 실행 |
| `Ctrl + Alt + C` | 캔버스 크기 조정 | 기준 축(Anchor Pivot) 설정 지원 |
| `Ctrl + U` | 색상 / 톤 보정 | 색조, 채도, 명도, 대비 실시간 조절 |
| `Ctrl + 0` | 화면 100% 뷰 리셋 | 캔버스를 원본 크기(100%) 및 화면 중앙으로 정렬 |
| `Space` + 드래그 / 휠 클릭 | 화면 이동 (Pan) | 캔버스 자유 이동 |
